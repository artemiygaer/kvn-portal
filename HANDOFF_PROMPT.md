# Передача проекта ИИ-агенту

Изучи [README](README.md), [архитектуру v5](v5/ARCHITECTURE.md),
[установку](v5/install/README.md) и [правила v5](v5/AGENTS.md). Работай с
проектом в WSL, общайся и пиши документацию по-русски. Текущая версия —
отдельная чистая установка портала управления Debian; дополнительное ПО
ставится только подписанными модулями из панели. Не изменяй рабочие данные,
ключи, существующие серверы или старые опубликованные релизы без отдельного
разрешения. Перед правками проверь состояние Git и соседний код, после —
релевантные тесты. Не публикуй секреты и не монтируй Docker socket в web.
