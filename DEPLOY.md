# Установка и обслуживание KVN Portal

Актуальные инструкции находятся в [руководстве v5](v5/DEPLOY.md) и
[описании интерактивного установщика](v5/install/README.md). Первичная
установка выполняется по SSH на чистом Debian; старые установки v4 не
обновляются поверх. Данные пользователей переносятся через `.kvn`.
