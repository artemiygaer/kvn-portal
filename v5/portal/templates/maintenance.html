Приватная копия ядра

Через SSH от root. В копии есть закрытые данные, поэтому панель не может её скачать. Пользовательские данные переносите отдельно через «Импорт и экспорт .kvn».

cd /usr/local/lib/kvn-v5
python3 -m v5.core.maintenance backup

Сохраните имя файла и SHA-256, которые покажет команда. Если при установке выбран другой каталог, перед командой backup укажите --install-dir /root/ИМЯ.

Если потерян доступ к панели

Подключитесь по SSH и смените пароль. Все старые сеансы панели будут завершены. TLS и VPN-модули команда не меняет.

cd /usr/local/lib/kvn-v5
python3 -m v5.core.maintenance reset-admin

Обновление ядра

Открыть обновления

Отдельно от модулей. В панели сначала проверьте подписанный пакет, затем подтвердите применение. Аварийный вариант через SSH:

cd /usr/local/lib/kvn-v5
python3 -m v5.core.maintenance core-update /root/КАТАЛОГ

При прерванном обновлении выполните python3 -m v5.core.maintenance core-recover. Для явного возврата к предыдущей рабочей версии добавьте --previous.
