Восстановление через SSH

Если результат не подтверждён, проверьте журнал службы. Прерванную транзакцию можно восстановить; предыдущую версию — вернуть отдельно.

journalctl -u 'kvn-v5-core-apply@*' -n 100 --no-pager
cd /usr/local/lib/kvn-v5
python3 -m v5.core.maintenance core-recover
# Для возврата предыдущей версии:
python3 -m v5.core.maintenance core-recover --previous

При нестандартном каталоге установки укажите --install-dir /root/ИМЯ перед командой core-recover.
