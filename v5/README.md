# KVN Portal-first v5

Лёгкий портал управления и наблюдения за отдельным сервером Debian 12/13.
После чистой установки дополнительные модули отсутствуют. Xray, WireGuard,
AmneziaWG, Hysteria2, Telemt и MTG можно установить и включить отдельно.
OpenConnect не входит в v5.

**v5 устанавливается только начисто**, не поверх работающего v4.2. Для
переноса пользователей используйте зашифрованный экспорт `.kvn`: импорт не
запускает сервисы и не переносит сетевые настройки или сертификаты.

По умолчанию настройки находятся в `/root/portal`, а код служб — в
`/usr/local/lib/kvn-v5`. Панель не получает Docker socket. Сбор истории и
root-консоль выключены, пока администратор не включит их явно. Новые установки
AmneziaWG используют 3.1 или более новую проверенную совместимую версию;
устаревший профиль допускается только при явном переносе.

Публичная страница использует TCP/80 и TCP/443, управление — HTTPS/8443.
До выпуска доверенного сертификата аварийный вход доступен только через
SSH-туннель на `127.0.0.1:8443`. Выпуск v5 и внешний ACME-прогон должны быть
подтверждены отдельно; локальные тесты не являются доказательством публичной
выдачи и автоматического продления.
