# MTG

Подписанный модуль устанавливается выключенным. У MTG один общий FakeTLS
секрет для разрешённых пользователей; персональная статистика не
заявляется. Настройки сохраняются при отключении.

Доступен общий TCP/443 по отдельному SNI и опциональный прямой TCP/2447.
Собственная маскировка явно направляется на локальный backend сайта
TCP/10443; внешняя проверяется по DNS, локальным IP и TLS. Для MTG 2.3
применяется `domain-fronting.host`. Совпадающие SNI двух бэкендов
отклоняются до применения.

Контейнер без root, capabilities и Docker socket; с read-only конфигом.
Администратор изменяет параметры только при выключенном модуле.
Имя и публикацию можно изменить в карточке модуля на портале; общий секрет
сохраняется. После смены SNI или порта передайте пользователям новые ссылки.

На изолированных Debian 12 и 13 проверен подписанный пакет: включение и отключение
через портал освобождают TCP/2447 и сохраняют настройки.
