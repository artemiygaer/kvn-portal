# Telemt

Подписанный модуль устанавливается выключенным. У каждого включённого
пользователя свой 16-байтный секрет FakeTLS; отключённым пользователям
ссылки не выдаются. Настройки и секреты сохраняются при остановке.

Доступен общий TCP/443 по отдельному SNI и опциональный прямой TCP/2446.
Собственный сайт можно выбрать явно: маскировка идёт на локальный
backend сайта TCP/10443, без петли через 443 и без доступа к админке 8443.
Внешняя маскировка перед запуском проверяется по DNS, локальным IP и TLS,
после чего применяется проверенный адрес. API и метрики Telemt выключены.
Работа конкретного внешнего домена зависит от сети.

Контейнер без root, capabilities и Docker socket; с read-only конфигом.
Администратор изменяет параметры только при выключенном модуле.
Имя и публикацию можно изменить в карточке модуля на портале; ключи
пользователей сохраняются. После смены SNI или порта передайте им новые ссылки.

На изолированных Debian 12 и 13 проверен подписанный пакет: включение и
отключение через портал освобождают TCP/2446 и сохраняют настройки. На Debian 12
при первых попытках были отказы без установленной причины; повторный цикл
через HTTPS и три цикла через системную службу прошли успешно.
