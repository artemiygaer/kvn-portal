# WireGuard

В панели на карточке выключенного модуля доступно создание начальных настроек.
Оно не перезаписывает существующие ключи и не включает интерфейс. Если не
указан исходящий интерфейс, клиенты получают доступ только к подсети туннеля;
для выхода в интернет также требуется включённая на сервере пересылка IPv4.

Стандартный WireGuard слушает UDP/51821 (`wg0`). Профиль AmneziaWG с UDP/51820 или AWG-полями для него не подходит. См. [диагностику и настройку туннелей](../host_tunnel/README.md).
