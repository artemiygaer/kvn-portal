# Модуль Xray

Установка подписанного пакета в разделе «Модули» не запускает Xray. Ядро не устанавливает Docker. Для включения модуля нужны рабочие Docker Engine и CLI `/usr/bin/docker`; в Debian 13 при установке без рекомендаций явно добавьте `docker-cli` к `docker.io`. Для общего входа TCP/443 нужен `libnginx-mod-stream` и действующий TLS сайта. Если на сервере уже настроен Docker, не переустанавливайте его.

- `tls`: VLESS с доверенным сертификатом, прямой TCP/2443 или отдельный SNI на TCP/443. Для TLS по IP — только прямой порт и сертификат с IP SAN.
- `reality-tcp`: VLESS Reality с Vision. Прямой TCP/2444 или отдельный маршрут SNI на TCP/443.
- `reality-xhttp`: VLESS Reality с xHTTP. Прямой TCP/2445 или отдельный маршрут SNI на TCP/443; нужен отдельный путь.

`direct` открывает только прямой порт, `shared` — только маршрут по SNI, `both` — оба. Для `self-steal` нужен общий вход `shared` или `both` и имя публичного сайта; обычный браузер видит сайт, а админка всегда остаётся на TCP/8443. Внешний Reality (`external`) использует чужой HTTPS-сайт, поддерживающий TLS 1.3; укажите его DNS-имя как `external_host`. Режимы и маршруты выбираются явно.

Поле `ipv4`: значение `0.0.0.0` означает все адреса и публикует выбранный прямой порт по IPv4 и IPv6, как это делает Xray. Для доступа только по IPv4 укажите конкретный IPv4 сетевого интерфейса. Если IPv6 выключен в ядре, используйте конкретный адрес и режим `direct` либо только `shared`.

## Ручное управление

Начните с выключенного модуля. Закрытый файл настроек (`0600`, закрытый родительский каталог) содержит схему и выдачу прав. Пример только с внешним Reality TCP; замените тестовые имена и UUID. Один UUID — одному пользователю. Поля `path`, `reality` и `external_host` должны быть `null`, если не используются этим профилем.

```json
{
  "schema": 1,
  "ipv4": "0.0.0.0",
  "profiles": [{
    "kind": "reality-tcp", "exposure": "direct", "sni": "target.example",
    "reality": "external", "external_host": "target.example", "path": null
  }],
  "accounts": [{
    "name": "example", "id": "f8b7598c-3411-4c0c-9824-4c5bc2af0f19", "grants": ["reality-tcp"]
  }]
}
```

```bash
cd /usr/local/lib/kvn-v5
sudo python3 -m v5.core.lifecycle.manage configure-xray /root/xray-settings.json
sudo python3 -m v5.core.lifecycle.manage enable xray
sudo python3 -m v5.core.lifecycle.manage disable xray
sudo python3 -m v5.core.lifecycle.manage status
```

На портале можно включить и отключить модуль после настройки профилей. Отключение убирает маршруты и слушающие порты, но сохраняет настройки и ключи. После проверки подписи активный пакет можно обновить отдельным действием: кратковременно отключается только модуль; при отказе возвращается последняя подтверждённая версия. Приватный ключ Reality не включается в ссылки или подписки. Экспорт по IP не подменяет имя SNI/сертификата.
