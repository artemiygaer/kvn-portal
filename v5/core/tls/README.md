# TLS публичного входа v5

- У каждого зарегистрированного имени свой сертификат с одним точным DNS SAN. Прямой вход по IPv4/IPv6 использует отдельный IP SAN; wildcard и совпадение только по CN не принимаются.
- TCP/80 отдаёт нейтральную публичную страницу и токены HTTP-01 только для зарегистрированных имён и IP. TCP/443 отдаёт ту же страницу при наличии сертификата. Панель на этапе первичной настройки остаётся на loopback:8443; самоподписанный bootstrap-сертификат не попадает на публичный вход.
- Для выпуска IP через webroot нужен Certbot 5.4.0 или новее. Используется профиль `shortlived` и отдельные каталоги/lineage для staging и production. Источник: [Let’s Encrypt — сертификаты IP в Certbot](https://letsencrypt.org/2026/03/11/shorter-certs-certbot/).
- Кандидат проверяется по SAN, сроку, цепочке и ключу до записи. Пара сохраняется в одном закрытом неизменяемом поколении. При применении конфигурации сначала проверяется кандидат, затем новый слушатель; при отказе восстанавливается прежняя конфигурация и проверяется её ответ.

В «Сертификаты HTTPS» можно поставить проверочный или публичный выпуск в очередь, посмотреть срок действующей пары и причину последнего отказа. Публичный и проверочный результаты отображаются раздельно; проверочный выпуск не заменяет активный сертификат. Таймер проверяет продление публичных lineages дважды в сутки. Для ACME-операций служба ожидает совместимый Certbot в отдельном окружении `/usr/local/lib/kvn-v5-acme/`.

Там же доступна диагностика зарегистрированных DNS-имён и импорт доверенной
PEM-цепочки с незашифрованным ключом. Импорт проверяет SAN, срок, цепочку и
соответствие ключа до замены; ключ не попадает в журнал. Импортированные пары
автоматически через ACME не продлеваются: следите за сроком и заменяйте их
вручную либо явно запустите публичный выпуск ACME.

Если после обновления ядра панель сообщает, что шлюз не подготовлен к импорту,
дождитесь завершения обновления и нажмите «Подготовить HTTPS-шлюз». TLS-служба
применит конфигурацию с проверкой и откатом. При ошибке проверьте состояние и
журнал `kvn-v5-tls.service`; до устранения ошибки импорт недоступен.

Выпуск сертификата требует доступного TCP/80 и корректного DNS. Если выпуск не удался, сохраняется вход через SSH-туннель. Для нового мастера внешний выпуск и продление на отдельном VPS пока не подтверждены; [инструкция проверки](EXTERNAL_TEST.md).
