# Единая карточка VPN-пользователя

Карточка хранит идентификатор пользователя и желаемые права. Включённый
модуль выдаёт профиль только после подтверждения, что нужная версия
настроек действительно работает. Выключение и удаление модуля не удаляют
право: карточка показывает «Модуль выключен» или «Ожидает установки».

## Границы

- Настройки и ключи принадлежат адаптерам модулей. Браузер получает статусы,
  пользовательские профили и QR, но не читает реестр или серверные ключи.
- У Xray и Hysteria2 права применяются к работающему серверу. Для модуля
  без адаптера карточки право можно сохранить, но нельзя считать активным
  или выдавать по нему профиль. Общий секрет MTG не является персональным
  доступом: отзыв права сам по себе не аннулирует ранее переданный секрет.
- Подписка содержит только готовые VLESS и Hysteria2-профили. Случайный
  URL-токен показывается при выпуске; в БД хранится только его хеш.
  Отзыв токена закрывает ссылку; для блокировки уже импортированных
  клиентских настроек отзовите также право на соответствующий протокол.

## Применение и проверка

Изменение права сохраняется до вызова адаптера. При сбое выполняется
попытка отката, а карточка предлагает повтор. Если восстановление не
подтверждено, профили не выдаются до сверки. Перед открытием портов при
старте модуль получает актуальные желаемые права; старое подтверждение
не разрешает выдачу нового профиля. Журнал восстановления закрыт от веба.

Быстрые проверки: `python3 -m unittest -v tests.v5.test_users tests.v5.test_gateway`.
Реальное поведение nginx: `python3 -m tests.v5.fixtures.check_users_nginx`
с локальным тестовым образом. Выдача и отзыв VLESS на штатном клиенте:
`python3 -m tests.v5.fixtures.check_xray_users_wsl` (изолированная сеть и
локальный закреплённый образ). Сквозной сценарий `tests.v5.users_lab_e2e`
запускается только на отдельной Debian VM: он устанавливает синтетические
пакеты, проверяет HTTPS, Unix RPC и фактическую выдачу/отзыв VLESS и QUIC.
