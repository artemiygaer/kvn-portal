# Проверка обновления портала

Дата: 14 ноября 2026. Стенд: отдельная виртуальная Debian 13 в WSL/QEMU,
SSH доступен только через loopback. Рабочие серверы не затронуты.

- Через настоящий HTTPS загружен подписанный пакет 5.0.1, проверены готовность
  и отдельный запуск. Получен статус `applied`; агент, веб-служба и шлюз активны.
- Подписанный пакет 5.0.2 содержал намеренный сбой запуска веб-службы. Через
  портал получен статус `failed`, служба автоматически восстановила 5.0.1;
  журнал незавершённой транзакции отсутствует, все три службы активны.
- До и после каждого сценария контрольные суммы настроек портала и реестра
  модулей совпали. Неверная подпись, CSRF, пути и состояние проверены отдельно
  автоматизированными тестами. Все 267 тестов v5 прошли, один пропущен.
- Проверен интерфейс в Chromium при ширине 360 и 1440 px: горизонтального
  переполнения страницы нет; загрузка, отдельное подтверждение и инструкции
  восстановления присутствуют. Скриншоты — локальные тестовые артефакты.

На 16 ноября опубликован предварительный RC, а загрузка обновления из
стабильного GitHub Releases ещё требует проверки. На отдельном внешнем стенде
проверены публичная выдача и принудительное продление сертификатов; плановое
продление по сроку ещё не подтверждено. Локальная VM его не заменяет.
