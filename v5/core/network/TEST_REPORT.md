# Доказательства фазы 5: сеть и lifecycle

Тесты выполнялись в WSL и отдельной Debian 13 VM QEMU. Рабочие серверы, релиз v4.2 и `relay/` не затрагивались. Клиенты и ключи синтетические; это доказательство сетевого ядра, а не поддержка клиентских протоколов.

| Критерий | Доказательство |
|---|---|
| Пакет установлен выключенным | Подписанный fixture WireGuard установлен без старта systemd unit. Из отдельного namespace UDP закрыт по IPv4/IPv6 и отсутствует в `ss`. Пустой план не создаёт SNI, NAT или listener. |
| Сайт и SNI на общем 443 | Debian/nginx: два реальных SNI backend, длинное имя, HTTPS-сайт и независимый 8443. Замена сертификата не сбросила маршруты. Отключение синтетического self-steal вернуло сайт напрямую на том же имени; соседний SNI остался. Откат и снятие последнего маршрута прошли без смены PID master nginx. |
| Внешний TCP/UDP IPv4/IPv6 | Отдельный клиент через veth отправил и получил данные по всем четырём комбинациям. Проверены отсутствие слушателя на DNAT-порту, защита внутреннего порта, реальная таблица nftables и закрытие после удаления. Чужая таблица не изменилась, одноимённая чужая отклонена. |
| Конфликты, отказ, прерывание | Реальный занятый UDP-порт отклонён до применения. Инъекция отказа nginx после reload и отказ healthcheck после systemd start откатились. SIGKILL до записи состояния оставил диск с журналом; reconcile закрыл неподтверждённый UDP. TCP/8443 оставался доступным. |
| Disable, upgrade, reboot, enable | Выключенный модуль обновлён подписанным пакетом. Reconcile и настоящий reboot не открыли UDP-порт; система загрузилась с новым boot ID. 80/443/8443 доступны, повторное включение вернуло трафик с неизменной контрольной суммой настроек и ключа. |

Журналы находятся в `output/v5-lab/`: `phase5-gateway-r3.log`, `phase5-nft-r3.log`, `phase5-lifecycle-r4.log`, `phase5-gateway-r6-retry.log` — exit=0. Последний прогон также проверил штатный reconcile под ограничениями systemd без активных модулей. Первые ошибки тестов задокументированы в спецификации восстановления фазы 5. WSL: 85 тестов v5, компиляция и архитектура — exit=0; 34 теста legacy — exit=0, из них 1 явный пропуск необязательного legacy Docker E2E.

Реальные проверки запускаются из корня проекта: `python3 -m tests.v5.network_gateway_e2e ARCHIVE`, с `--nft` для DNAT и `python3 -m tests.v5.lifecycle_e2e ARCHIVE` для reboot. Скрипты проверяют identity и используют только заданную учебную VM на loopback SSH.
