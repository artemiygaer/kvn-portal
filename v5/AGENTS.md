# Работа над KVN Portal-first (v5)

- На этом Windows-устройстве команды разработки, Git, сборку и тесты всегда запускайте в WSL. Для рабочей копии на диске Windows используйте её путь `/mnt/...`, для образов лабораторных VM — файловую систему WSL.
- Файлы и тесты новой линейки держите отдельно от v4.2. Не изменяйте рабочие серверы, опубликованный релиз v4.2 и `relay/`. Для проверки systemd, установки и reboot используйте только изолированные гостевые Debian внутри WSL.
- Общайтесь с пользователем по-русски; комментарии и документацию также пишите по-русски. Текущие критерии и границы работ находятся в `.supergoal/kvn-portal-first-clean-install-ckplYK/`.
- По уточнению пользователя новые установки AmneziaWG используют 3.1 или более новую проверенную совместимую версию. Не делать fallback на legacy при старом kernel/tools. Сохранённые legacy-конфиги — только совместимость явного переноса; не переключать их без подтверждённой миграции и переэкспорта клиентов. Правило legacy-default из v4.2 на новые установки v5 не распространяется.
