Обновление и экспорт

Два источника используют один проверяемый updater.

  • Портал: «Настройки» → ручная загрузка или GitHub → проверка → состояние ready → отдельный запуск с root-паролем.
  • Private GitHub token задаётся только через серверный getpass и хранится root-only; не вставляйте его в портал или чат.
  • Экспорт пользователя: скачайте «ZIP для Telegram» и прикрепите к сообщению вручную либо скопируйте send.txt. Прямой отправки через Telegram API нет.
  • IP-экспорт меняет endpoint, но сохраняет SNI и certificate identity; IP-подписке нужен точный IP SAN.
