# KVN Portal

Лёгкий портал управления и наблюдения за сервером Debian 12/13 с подключаемыми
модулями. Новая версия v5 предназначена для чистой установки; после неё
дополнительных модулей и Docker нет. Нужные модули устанавливаются, включаются
и отключаются через панель; конфигурация при отключении сохраняется.

**Состояние:** v5 разрабатывается и ещё не опубликована. Инструкции ниже
относятся к ней; до публикации установочные ссылки v5 не работают. Настройка
модулей и подготовка их системных зависимостей через портал ещё дорабатываются.

## Установка и обновление

Первичная установка выполняется от root по SSH из проверенного архива GitHub Releases
либо из заранее загруженного архива. Интерактивный мастер по умолчанию
использует `/root/portal`. [Пошаговая установка](v5/install/README.md) включает
проверку SHA-256 и первый безопасный вход.

Последующее обновление портала и установка модулей доступны в интерфейсе:
подписанный архив получают из GitHub или загружают вручную, затем отдельно
подтверждают применение. При аварии остаётся восстановление по SSH.

## Возможности

- Мониторинг сервера, SSH-сессий и процессов; история по запросу.
- Публичная страница на TCP/80 и HTTPS TCP/443, администрирование по HTTPS на
  TCP/8443. Поддерживаются IP и несколько имён с отдельными сертификатами.
- Управление модулями Xray, WireGuard, AmneziaWG, Hysteria2, Telemt и MTG;
  установка модуля сама по себе не включает сервис и не открывает его порты.
- Импорт зашифрованного `.kvn` из версии 4.2. Интерактивная root-консоль и
  сбор истории по умолчанию выключены.

Портал не получает Docker socket: привилегированные операции выполняет
ограниченный агент. До настройки доверенного сертификата вход доступен через
SSH-туннель и проверенный локальный сертификат.
